# Text-tools adoption captures

Light- and dark-theme captures of the built-in editor with the shared
Planchette text-tools surface at the adoption revision. Generated by
`test/ui/built_in_editor_capture_test.dart`
(`captures the text-tools browser and tool bar`) with real fonts:

```bash
cd app/poltergeist_app
POLTERGEIST_CAPTURE=1 \
POLTERGEIST_CAPTURE_DIR=../../tasks/planchette-text-tools/screenshots \
flutter test test/ui/built_in_editor_capture_test.dart \
  --plain-name "captures the text-tools browser"
```

- `editor-text-tools-{light,dark}.png`: the header icon's catalog browser
  with the filter narrowed to `sort` (header icon, ARB-driven title,
  filter hint, group heading, Repeat row, and tool rows with
  descriptions).
- `editor-tool-bar-{light,dark}.png`: the Sort Lines options bar (scope
  line, option labels, live count, Apply/Close).

Fonts: DejaVu Sans / DejaVu Sans Mono from `$HOME/.local/share/fonts`
plus Flutter's cached MaterialIcons; boxes replace glyphs when the host
has no fonts. The pin revision and test counts are recorded in
`docs/PORTS.md` and `docs/STATUS.md`.
